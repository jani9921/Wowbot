- "minden jó" jelentést adni anélkül, hogy ténylegesen végignézted a teljes repo call-site-jait;

3. CANONICAL INVARIANTS
=================================================

Kódba és tesztekbe rögzíts invariánsokat.

Minimum:

INVARIANT A
Egyszerre legfeljebb 1 ActiveSkill lehet RUNNING/STARTING.

INVARIANT B
Planner nem mutálhat közvetlen executor vagy skill belső state-et.

INVARIANT C
WorldModel nem küld inputot.

INVARIANT D
Executor nem értelmez questet, target role-t vagy planner döntést.

INVARIANT E
RUNNING skill alatt nincs normál planner re-entry.

INVARIANT F
Quest objective stage változás invalidálja a régi objective-localization beliefet.

INVARIANT G
Loading / teleport / phase change invalidálja a screen-space és local-route state-et.

INVARIANT H
Action success nem jelent automatikusan quest-credit success-t.

INVARIANT I
Non-retryable failure után ugyanaz a DecisionFingerprint nem adható ki új evidence nélkül.

INVARIANT J
Cancel / fatal error után nincs held key.

INVARIANT K
Minden terminal skill állapot typed reasonnal és eventtel zárul.

INVARIANT L
Egyetlen navigation authority létezik.

INVARIANT M
Egyetlen stuck detector authority létezik.

INVARIANT N
Egyetlen UI-context owner létezik.

Írj ezekhez automatikus architecture guard / runtime assertion teszteket.

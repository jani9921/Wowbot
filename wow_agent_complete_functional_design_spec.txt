DESIGN SPECIFICATION – V1
============================================================

DOKUMENTUM CÉLJA
================

Ez a dokumentum NEM implementációs prompt és NEM kész kód.

A célja a meglévő autonóm World of Warcraft kliens-agent teljes funkcionális megtervezése úgy, hogy a rendszer minden fontos részegységéről egyértelmű legyen:

- MI a feladata;
- MI NEM a feladata;
- KI birtokolja az adott state-et;
- MILYEN adatot kap;
- MILYEN adatot ad vissza;
- MILYEN publikus funkciókat kell biztosítania;
- MILYEN belső állapotokkal működik;
- MILYEN eseményeket fogad;
- MILYEN eseményeket bocsát ki;
- MILYEN hibákat kezel lokálisan;
- MIKOR kér magasabb szintű újratervezést;
- MILYEN fallbackeket használ;
- MILYEN időzítéssel fusson;
- MILYEN tesztekkel igazolható a helyes működés;
- HOGYAN kapcsolódik a többi komponenshez.

A dokumentum a jelenlegi repositoryban látható konkrét modulokból indul ki, többek között:

A jelenlegi modulnevek NEM kötelezőek a végállapotban.
A felelősségi határok viszont kötelezőek.

A terv a modern WoW questelési működéséből indul ki:

- Quest Tracker / Quest Log;
- World Map;
- quest- és turn-in markerek;
- supertracking / navigation cue, amikor elérhető;
- Minimap;
- 3D világ;
- Interact Key / interakciós kiemelés;
- target frame / nameplate / tooltip;
- quest tool button;
- gossip / quest offer / quest complete / reward UI;
- Extra Action Button;
- vehicle / override UI;
- loading / cinematic / phasing;
- több lépcsős quest objective-ek.

ALAPELV:

A quest objective NEM köteles a kamera előtt lenni.

A helyes quest végrehajtási modell:

QUEST STATE
→ OBJECTIVE CLASSIFICATION
→ OBJECTIVE LOCALIZATION
→ GLOBAL / REGIONAL / LOCAL / IMMEDIATE NAVIGATION
→ TARGET OR MECHANIC ACQUISITION
→ DETERMINISTIC SKILL EXECUTION
→ ACTION VERIFICATION
→ QUEST CREDIT VERIFICATION
→ QUEST STATE RE-READ
→ NEXT STAGE / TURN-IN

============================================================
2. GLOBÁLIS ARCHITEKTURÁLIS INVARIÁNSOK
============================================================

INV-01
Egyszerre pontosan 0 vagy 1 aktív Skill lehet.

INV-02
A Planner nem küld közvetlen billentyűt/egérinputot.

INV-03
A WorldModel nem indít skillt.

INV-04
Az Executor nem tud quest objective-ről.

INV-05
A Verifier nem hajt végre actiont.

INV-06
A NavigationService az egyetlen navigációs authority.

INV-07
A StuckDetector az egyetlen stuck authority.

INV-08
A QuestProgressVerifier az egyetlen komponens, amely quest-credit sikert mondhat ki.

INV-09
Skill success != quest success.

INV-10
Quest stage változás invalidálja a régi objective localization state-et.

INV-11
Loading/teleport/phasing invalidálja a lokális screen-space és route state-et.

INV-12
Cancel/fatal után nincs lenyomva maradt billentyű.

INV-13
Nincs végtelen retry.

INV-14
Nincs végtelen local search.

INV-15
Ugyanaz a non-retryable planner-döntés új evidence nélkül nem ismételhető korlátlanul.

INV-16
Minden coordinate object explicit coordinate_space-et hordoz.

INV-17
Egy adatmezőnek egyetlen writer-owner komponense lehet.

INV-18
Raw detector output nem folyhat közvetlenül a Plannerbe; normalizálás/fusion szükséges.

INV-19
Quest objective hiánya a 3D képen nem jelent "objective not found"-ot.

INV-20
A rendszer képes koordináta nélküli cue-based navigációra is.

101. KUTATÁSI ALAP ÉS WOW-SPECIFIKUS TERVEZÉSI MEGJEGYZÉSEK
============================================================

A tervezésnél figyelembe vett WoW UI-viselkedések:

- A Map & Quest Log egyesíti a zóna térképet és quest információkat, és objective-ekhez térképi információt ad.
- A modern world map többféle quest és világikont kezel, és több ikon supertrackelhető.
- Az Interact Key NPC-k és objektumok interakciójára használható; interaktív célok megfelelő közelségben/facingnél kiemelhetők.
- Az Interact Key quest-item jellegű interakciókban is használható.
- A modern WoW támogat campaign/main-story jellegű quest megkülönböztetést.
- A questelésben előfordul Scouting Map / UI-választás, special action, vehicle, scripted event és field jellegű completion.
- Emiatt egy kizárólag 3D detectorra vagy kizárólag waypoint koordinátára épülő quest agent nem elegendő.

A rendszer ezért több információs skálát egyesít:

GLOBAL:
World Map

REGIONAL:
Minimap / navigation cue

LOCAL:
3D scene / entity search

IMMEDIATE:
target / facing / interact / combat

Ezt a négy szintet a teljes quest rendszer alapmodelljének kell tekinteni.
